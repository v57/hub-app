# Keyboard Shortcuts

Hub has no menu commands of its own. These keys work on the Mac, and on iPad with a keyboard.

| Keys | Where | What it does |
|---|---|---|
| Return | A sheet or dialog | Confirms: the sheet’s main button, such as **Connect**, **Pair**, **Join**, **Share** or **Done** |
| Escape | A sheet or dialog | Cancels: the sheet’s **Cancel** button |
| ⌘[ | A camera’s page | Goes back to **Cameras** |

On iPhone, a camera’s page opens on a page of its own; go back with the bar’s back button.
